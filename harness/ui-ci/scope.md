# Public CI trial scope

The current user authorized the fixed pilot content and operations, then selected public GitHub repositories. Exact messages and scope are retained in `harness/evidence/ci-platform-authorization.json`.

Reuses the accepted native implementation, original D/A, original test selection and two dedicated simulators. Native UI adds platform evidence; original requirement Gate obligations remain independent. No product code change, Apply, Archive, merge or release. App retains its adopted requirement records; game retains its archived Change and unique Tasks. Old approvals and runs remain historical facts. The public endpoint is an authorized access choice, not a new design approval or final run acceptance.
